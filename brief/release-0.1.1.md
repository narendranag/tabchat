**New:** GitHub is now a built-in service. Add it with **+**. Each GitHub account gets its own sign-in, and links to GitHub's own file and asset sites stay inside Tabchat. GitHub doesn't show its notification count in the page title, so its unread badge stays empty.

Everything from [0.1.0](https://github.com/narendranag/tabchat/releases/tag/v0.1.0) is unchanged. Your services and sign-ins carry over when you replace the app.

**Requirements:** macOS 14 Sonoma or later, Apple Silicon.

**Opening it the first time:** this build is signed with a development certificate but **not notarised**, so macOS blocks a normal double-click on other Macs. Drag Tabchat to Applications, then right-click it → **Open** → **Open**. Or go to System Settings → Privacy & Security → **Open Anyway**.
