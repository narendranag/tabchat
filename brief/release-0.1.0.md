The first release of Tabchat for Mac: a native Swift rewrite of [MMV2408/tabchat](https://github.com/MMV2408/tabchat) (Electron, Linux).

**What's in it:** WhatsApp, Discord, Teams, Outlook, OneDrive, Brightspace, Reddit, X and any website as services in one window, with:
- a sidebar of service icons;
- several accounts per service;
- one Microsoft sign-in shared by Teams, Outlook and OneDrive;
- unread badges on the Dock and in the menu bar;
- native notifications, with pause and per-service mute;
- start at login;
- split view, a `Cmd+K` quick switcher and sleeping services.

**Requirements:** macOS 14 Sonoma or later, Apple Silicon.

**Opening it the first time:** this build is signed with a development certificate but **not notarised**, so macOS blocks a normal double-click on other Macs. Drag Tabchat to Applications, then right-click it → **Open** → **Open**. Or go to System Settings → Privacy & Security → **Open Anyway**.
