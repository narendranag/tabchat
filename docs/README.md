# Tabchat documentation

A native macOS app that brings WhatsApp, Discord, Teams, Outlook, OneDrive, Brightspace and any website into one window via a sidebar of service icons, all sharing the system's own web engine (WKWebView). Rewritten from scratch in Swift, macOS 14+, Apple Silicon only, targeting users who want a single native app instead of bouncing between browsers and standalone clients.

**Status:** design and early implementation. Early phases (Engine spike, Skeleton) are complete; Core integration is underway. See `TASKS.md` at the project root for current status.

## Terms used throughout

| Term    | Meaning                                   |
| ------- | ----------------------------------------- |
| WKWebView | The system WebKit browser engine (same as Safari); used by Tabchat to display services |
| Service | A web app or website (WhatsApp, Discord, Teams, etc.) shown in a sidebar tab |
| Tab | One instance of a service; the app can have multiple tabs of the same service (e.g. two WhatsApp accounts) |
| Profile | A `WKWebsiteDataStore` for one sign-in; shared by related services (e.g. Teams, Outlook, OneDrive via "microsoft-work") |
| Unread | A count badge on a service tab, the Dock icon and menu bar |
| Focus | macOS notification Focus modes; Tabchat respects them before showing notifications |
